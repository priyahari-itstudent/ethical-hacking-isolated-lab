# Ethical Hacking: Legal Scope and Isolated Lab

## 1. Objective
To build an isolated practice environment and understand
the basics of ethical hacking and web application security.

## 2. Target Application
OWASP Juice Shop is a deliberately vulnerable web
application designed for security training.

## 3. Lab Environment
- Host Operating System: Windows 10
- Practice Target: OWASP Juice Shop
- Environment: Local, isolated lab
- Purpose: Educational security testing

## 4. Rules of Engagement
1. Test only systems explicitly authorized for testing.
2. Do not test third-party websites or systems.
3. Keep the practice application isolated.
4. Do not expose the lab to public networks.
5. Stop testing if unexpected issues occur.

## 5. Scope of Testing
- Configure the authorized practice application.
- Explore basic web application functionality.
- Document observations and learning outcomes.
- Perform only authorized security checks.

## 6. Evidence
Screenshots and verified configuration details will be
added after the practice lab is successfully configured.

## 7. Conclusion
This project demonstrates the importance of legal,
controlled, and responsible security testing.
